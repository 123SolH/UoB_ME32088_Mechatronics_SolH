# Simulink Templates

This folder contains MATLAB/Simulink models for simulation and control systems.

## Files

- **HW_Stepper_Motor.slx** - Simulink model for stepper motor simulation and control

## About Simulink

Simulink is a block diagram environment for multidomain simulation and model-based design. It is used for:
- Control system design and analysis
- Signal processing
- Hardware-in-the-loop (HIL) simulation
- Real-time system simulation

## File Format

- **.slx** - Simulink model file (MATLAB R2011b and later format)

## Usage

To open and edit these files:
1. Ensure MATLAB and Simulink are installed
2. Open MATLAB
3. Open the .slx files from the File menu or MATLAB workspace
4. Edit blocks and parameters as needed
5. Run simulations to test control strategies

## Contents

### HW_Stepper Motor
A hardware-focused Simulink model for stepper motor control in the Raspberry Pi, including:
- Driver control logic
- Step/direction control signals

## Requirements

- MATLAB (R2025b)
- Simulink
- Control System Toolbox (recommended)
- Matlab Support Package for Raspberry Pi Hardware
- Simulink Support Package for Raspberry Pi Hardware
- Simulink Coder (for code generation)
