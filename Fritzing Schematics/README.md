# Fritzing Schematics

This folder contains circuit schematics and breadboard layouts created using Fritzing.

## Files

- **Stepper Motor.fzz** - Stepper motor circuit schematic and breadboard layout
- **EE40221_Fritzing Sketches/** - Collection of Fritzing projects for EE40221 course

## About Fritzing

Fritzing is an open-source tool for designing and documenting electronics projects. It allows you to:
- Create schematic diagrams
- Design breadboard layouts
- Generate PCB designs
- Export designs in various formats

## File Format

- **.fzz** - Fritzing project file (contains schematic, breadboard, and PCB views)

## Usage

To view or edit these files:
1. Download Fritzing from https://fritzing.org
2. Open the .fzz files in the Fritzing application
3. Switch between Breadboard, Schematic, and PCB views as needed

## Contents

### Stepper Motor
Schematic and breadboard layout for stepper motor control circuits, likely including driver circuitry and control logic.
